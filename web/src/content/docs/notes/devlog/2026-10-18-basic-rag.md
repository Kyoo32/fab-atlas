## 3. 과정

### 3-1. 파싱 (`fabatlas/corpus.py`)

원문에 섹션 제목이 표시 없는 한 줄로만 있어서 판별이 애매했어요. `fetch_corpus.py`가 `== 제목 ==`을 남기도록 고치고, **같은 revision_id로** 다시 받았어요.

```bash
uv run scripts/fetch_corpus.py   # revision_id가 있으면 그 판을 다시 받아요
```

- `sources.csv`의 판 번호는 하나도 바뀌지 않았고, 원문은 제목 줄 표시 말고는 같아요.
- 제외 섹션: References, See also, External links, Further reading, Notes + 같은 성격의 Bibliography, Related links
- 무관 섹션은 지우지 않고 표시만 했어요: 16개, 1,727단어 (Silicon dioxide의 Geology·Biology·Health effects, Ion implantation의 metal finishing 등)
- 결과: 문서 23개, 섹션 296개. 위치는 모두 원문 기준 글자 위치예요.

- 답변의 인용 표시가 검색된 청크에 실제로 있는지 확인해요. 없으면 지어낸 인용으로 경고해요.

- Q5: 거절은 LLM 단계라 검색 기준으로는 판정을 보류했어요. top-1 점수 0.506은 Q4의 0.542와 차이가 작아서, 점수만으로 "답 없음"을 가르기는 어려워 보여요.

### 3-6. 답변 기준 판정

같은 top-5 청크로 답변을 만들고, 질문별 통과 기준을 노트북의 자동 규칙으로 확인했어요. 인용 일치는 "기대 섹션의 원문 위치와 겹치는 청크를 인용했는가"예요.

| # | 답변 요지 | 인용 | 거절 | 판정 |
| --- | --- | --- | --- | --- |
| Q1 | 빛을 받은 부분이 화학적으로 바뀌어 현상액으로 제거되거나 남고, 패턴이 전사돼요 | S007§1, S006§7 | 아니요 | 통과 |
| Q2 | 결정 손상 복구 + 도펀트 활성화 | S013§10, S013§6 | 아니요 | 통과 |
| Q3 | 반응성 이온이 주로 수직으로 도달해서 이방성이에요. 받침대 음전압 메커니즘은 없어요 | S011§3 | 아니요 | 부분 |
| Q4 | "EDS 공정에서 무엇을 검사하는지에 대한 근거를 코퍼스에서 찾을 수 없어요." | - | 예 | 실패 |
| Q5 | "코퍼스에서 삼성 3나노 공정의 수율에 관한 근거를 찾을 수 없어요." | - | 예 | 통과 |

- Q4 원인: 검색은 Wafer testing(S018§1, WPT·WFT 설명)을 3위로 가져왔어요. 그런데 근거 어디에도 "EDS"라는 말이 없어서 모델이 거절했어요. 검색과 답변 두 단계 모두 **표현 불일치**가 원인이에요.
- 지어낸 인용(검색 밖 청크 인용)은 0건이었어요.
- 프롬프트를 지키지 않은 부분: 인용을 문장마다 달지 않고 답변 끝에 모아 달았어요(답한 3개 모두). Q1은 "~합니다"와 "~해요"가 섞였어요. 거절 문장도 지시한 문장 그대로가 아니었어요. 프롬프트는 아직 고치지 않았어요.
- 온도 0인데도 실행마다 인용 목록이 조금 달랐어요. Q1은 한 번은 S006§6을 더 인용했어요.
- 판정 규칙 버그 2개를 고쳤어요: 거절 문장 어순이 다르면 거절로 못 잡던 것, Q5의 "3나노" 속 숫자 3을 지어낸 수치로 잘못 보던 것.

- "근거가 없으면 거절하라"는 안전장치가 표현만 다른 정답까지 거절하게 만들었어요. 환각과 [과잉 거절](/fab-atlas/notes/glossary/#과잉-거절-false-refusal)은 한쪽을 누르면 다른 쪽이 올라오는 트레이드오프예요.
- top-1 점수가 Q5 0.506, Q4 0.542로 비슷해서, 점수 기준만으로는 "답 없음"과 "표현 불일치"를 구분할 수 없어요.

### 3-8. 10분 실험: BM25는 한국어 질문으로 영어 문서를 찾을까?

같은 청크에 rank-bm25를 걸고, 질문 2개를 (a) 한국어 그대로 (b) 영어로 번역해서 검색했어요. 영어 번역은 Claude가 했어요.

| 질문 | 방식 | top-3 |
| --- | --- | --- |
| Q2 | (a) 한국어 | 모든 청크 점수 0 (순위 의미 없음) |
| Q2 | (b) 영어 번역 | S013§6, S013§10, S013§7 Ion implantation (19.0 / 18.2 / 17.4) |
| Q4 | (a) 한국어 | 모든 청크 점수 0 (순위 의미 없음) |
| Q4 | (b) 영어 번역 | S002§4, S002§5 Czochralski method, S015§4 Physical vapor deposition (12.8 / 12.5 / 12.0) |

- 결론: BM25는 교차언어 검색을 못 해요. 번역하면 Q2는 찾지만, Q4는 코퍼스에 "EDS"가 없어서 번역해도 못 찾아요.
- 9조합 시사점: BM25 축은 "한국어 질문 → 영어 번역 → BM25"로 정의하고, 번역 품질도 변수로 기록해요.
