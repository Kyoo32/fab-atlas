## 3. 과정

### 3-1. 저장소와 사이트 구조

한 저장소, 한 사이트 안에 두 영역을 나눴어요. ([D-006](/fab-atlas/notes/decisions/#d-006--문서-사이트-astro--starlight-두-영역-분리))

| 영역 | 누가 보나 | 무엇을 담나 |
| --- | --- | --- |
| 쇼케이스 (`/`, `/report/`) | 면접관과 방문자 | 프로젝트 소개, 8대 공정 띠, v1·v2 소개, 진행 현황, 검증 리포트 |
| 작업노트 (`/notes/`) | 나 (공부·작업 기록) | 타임라인, 작업일지, 용어사전, 결정 기록, 노트북 |

디자인 로드맵:

| 단계 | 쇼케이스에 더하는 것 |
| --- | --- |
| v0 | 깔끔한 기본형 (지금) |
| v1 | 실험 비교 차트 |
| v2 | 파이프라인 시각화 |
| v3 | 인터랙티브 공정 지도 |

```bash
npm create astro@latest web -- --template starlight
gh repo create Kyoo32/fab-atlas --public
gh api -X POST repos/Kyoo32/fab-atlas/pages -f build_type=workflow
```

### 3-2. 라이선스 판별 규칙

| 확인 | 결과 |
| --- | --- |
| CC BY 또는 CC BY-SA 표시가 있나? | 코퍼스 가능 (출처 표기) |
| 공공누리 제1유형(출처표시)인가? | 가능. 한국 공공기관 자료 경로 |
| CC BY-NC 계열인가? | 보류. 가능하지만 라이선스가 섞이면 관리가 복잡해져요 |
| 아무 표시도 없나? | 불가. 표시가 없으면 기본값은 "모든 권리 보유"예요 |

"금지한다는 말이 없으니 괜찮다"가 아니라 "허락한다는 표시가 없으면 안 된다".

### 3-4. 코퍼스 구조: 기본 문서 > 상세 문서

**후보 (직접 확인 전)**

| 확인 | 공정 | 기본 문서 | 상세 문서 후보 |
| --- | --- | --- | --- |
| ☐ | 웨이퍼 제조 | Wafer (electronics) | Czochralski method, Chemical-mechanical polishing |
| ☐ | 산화 | Thermal oxidation | Silicon dioxide |
| ☐ | 포토 | Photolithography | Photoresist, Extreme ultraviolet lithography |
| ☐ | 식각 | Etching (microfabrication) | Plasma etching, Reactive-ion etching |
| ☐ | 증착·이온주입 | Chemical vapor deposition, Ion implantation | Atomic layer deposition, Physical vapor deposition |
| ☐ | 금속배선 | Interconnect (integrated circuits) | Copper interconnects, Damascene process |
| ☐ | EDS | Wafer testing | Probe card |
| ☐ | 패키징 | Integrated circuit packaging | Flip chip, Through-silicon via, Wafer dicing |

이 구조로 "기본 문서에 답이 있는 질문"과 "상세 문서에 답이 있는 질문"의 검색 성능을 나눠 볼 수 있어요.

### 3-5. sources.csv 컬럼

```csv
id,process,level,parent_id,title,url,language,license,revision_id,collected_at,notes
```

| 컬럼 | 설명 | 예시 형식 |
| --- | --- | --- |
| `id` | 문서 고유 번호. 한 번 정하면 바꾸지 않아요. | `S001` |
| `process` | 8대 공정 중 하나. 아래 여덟 값만 써요. | `식각` |
| `level` | 문서 단계. `기본` 또는 `상세` | `상세` |
| `parent_id` | 상세 문서가 속한 기본 문서의 `id`. 기본 문서는 비워요. | `S001` |
| `title` | 원문 문서 제목 | 원문 그대로 |
| `url` | 원문 주소 | `https://…` |
| `language` | 문서 언어 코드 | `en` |
| `license` | 라이선스 표기 | `CC BY-SA 4.0` |
| `revision_id` | 위키백과 판 번호. `scripts/fetch_corpus.py`가 채워요. 같은 판을 다시 받을 때 써요. | `1375104544` |
| `collected_at` | 수집한 날짜 | `2026-10-14` |
| `notes` | 범위, 주의할 점 등 메모 | 자유 |

`process` 허용 값: `웨이퍼 제조`, `산화`, `포토`, `식각`, `증착·이온주입`, `금속배선`, `EDS`, `패키징`
