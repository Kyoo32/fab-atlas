### 3-2. 위키백과 한국어·영어판에서 문서 찾기

공정마다 한국어판(ko.wikipedia.org)과 영어판(en.wikipedia.org)을 함께 찾아봐요.

### 3-3. 라이선스 확인

위키백과 본문은 CC BY-SA 4.0이에요. 문서 하단의 라이선스 표기를 확인하고, 다른 출처는 페이지마다 라이선스를 따로 확인해요. 재배포가 허용되지 않으면 기록하지 않아요.

### 3-4. sources.csv에 한 줄씩 기록

```csv
id,process,title,url,language,license,collected_at,notes
```

| 컬럼 | 설명 | 예시 형식 |
| --- | --- | --- |
| `id` | 문서 고유 번호. 한 번 정하면 바꾸지 않아요. | `S001` |
| `process` | 8대 공정 중 하나. 아래 여덟 값만 써요. | `식각` |
| `title` | 원문 문서 제목 | 원문 그대로 |
| `url` | 원문 주소 | `https://…` |
| `language` | 문서 언어 코드 | `ko`, `en` |
| `license` | 라이선스 표기 | `CC BY-SA 4.0` |
| `collected_at` | 수집한 날짜 | `2026-10-13` |
| `notes` | 판(revision), 범위, 주의할 점 등 메모 | 자유 |

`process` 허용 값: `웨이퍼 제조`, `산화`, `포토`, `식각`, `증착·이온주입`, `금속배선`, `EDS`, `패키징`
