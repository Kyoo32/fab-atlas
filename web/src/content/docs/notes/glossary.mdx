### Recall@5

<Badge text="초안" variant="caution" />

| 칸 | 내용 |
| --- | --- |
| 한 줄 정의 | 찾아야 할 정답 근거가 검색 상위 5개 안에 들어오는 비율 |
| 비유 |  |
| 이 프로젝트에서는 | 상위 5개 청크 중 하나라도 정답 근거(doc_id + 글자 범위)와 겹치면 맞힘. 답없음 빼고 45문항, 1문항 = 2.2%p |
| 헷갈리는 것 | Precision@5는 "가져온 5개 중 정답 비율"이에요. 대부분 문항은 근거가 1곳이라 Precision@5는 최대 0.2라서 비교 지표로 안 써요. 엄밀히는 "하나라도 들어오면 맞힘"(Hit@5)이고, 근거가 1곳인 문항에서는 Recall@5와 같아요. |

### 하이브리드 검색 · RRF (Reciprocal Rank Fusion)

<Badge text="초안" variant="caution" />

| 칸 | 내용 |
| --- | --- |
| 한 줄 정의 | 검색기 두 개의 순위표를 등수로 합치는 방법. 점수 = Σ 1/(k + 등수), k = 60 |
| 비유 |  |
| 이 프로젝트에서는 | dense(bge-m3, 한국어 그대로)와 BM25(영어 번역)의 순위를 RRF로 합쳐요(D-014). w500o100에서는 dense의 틀린 순위가 섞여 BM25(1.000)보다 낮았고(0.956), blind에서는 가장 높았어요(0.708). |
| 헷갈리는 것 | RRF는 검색기가 아니라 합치는 규칙이에요. 점수 단위가 달라서(BM25 0\~20, 코사인 0\~1) 점수 대신 등수를 써요. 예: BM25 1등·dense 10등(0.0307)보다 둘 다 3등(0.0317)이 위로 가요. |
